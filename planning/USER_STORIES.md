# CadreOS User Stories

## MVP Stories (Initial Issue Seed List)

### Epic: Identity and Roles
1. As an admin, I want to invite users and assign roles so the right people can access the system.
2. As a coach, I want one user to hold multiple roles (coach + parent) so access reflects real responsibilities.

### Epic: Teams and Rosters
3. As staff, I want to create programs/teams/seasons so operations are organized.
4. As a coach, I want to manage roster membership so team data stays current.

### Epic: Notes and Records
5. As a coach, I want to quickly capture an observation from mobile so details are not lost.
6. As staff, I want notes linked to athletes and teams so history is searchable.

### Epic: Communication Routing
7. As staff, I want an inbox triage queue so incoming communication is prioritized.
8. As an admin, I want role-aware routing rules so sensitive communication is only visible to authorized users.

### Epic: Events and Attendance
9. As a coach, I want to schedule practices/games so participants have a shared calendar.
10. As an athlete/parent, I want to RSVP availability so coaches can plan accurately.
11. As staff, I want to record attendance so participation can be tracked over time.

### Epic: Tasks and Follow-Up
12. As a coach, I want to create a follow-up task from a note or message so action is accountable.
13. As an assignee, I want due dates and reminders so I can complete tasks on time.

### Epic: Audit and Reporting
14. As an admin, I want an audit log for key actions so decisions are traceable.
15. As leadership, I want basic attendance and workflow metrics so we can improve operations.

## Suggested First GitHub Issues (MVP Order)
1. Define role model and permissions matrix
2. Implement program/team/season and roster data model
3. Build mobile note capture with athlete/team linking
4. Create inbox triage workflow and routing metadata
5. Implement event scheduling and RSVP flow
6. Implement attendance capture and status taxonomy
7. Add task creation from note/message/event
8. Add audit events for CRUD and workflow transitions
9. Add baseline operational reporting views
