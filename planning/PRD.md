# CadreOS PRD (MVP-Oriented)

## Product Name
CadreOS

## Category
Athlete Program Operating System

## Objective
Deliver an MVP that enables programs to manage people, communication, scheduling, attendance, and action tracking in one system.

## MVP Scope
1. Identity, roles, and relationships
2. Teams/program structure and rosters
3. Notes and observation capture
4. Inbox triage and communication routing
5. Event scheduling and calendar
6. Attendance and participation tracking
7. Basic tasks and follow-up workflows

## Functional Requirements
- User authentication and role-based access
- Program/team/roster management
- Quick note capture with athlete/program linkage
- Routing rules for who can view/respond to messages
- Event creation, assignment, and RSVP/attendance recording
- Task assignment with due date, owner, status
- Immutable activity and audit history for key actions

## Non-Functional Requirements
- Mobile-first responsive UX
- Data privacy and least-privilege access
- Reliable notifications
- Basic analytics dashboards for participation and operations

## Success Metrics (Initial)
- Weekly active users by role
- Note-to-action conversion rate
- Event attendance completion rate
- Task completion rate on time
- Median response time for routed communications

## Out of Scope (MVP)
- Deep finance and billing
- Advanced AI prediction tooling
- Extensive external integrations
