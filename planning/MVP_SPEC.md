# CadreOS MVP Specification

## MVP Goal
Enable one sports program to manage people, roles, teams, notes, events, attendance, and follow-up tasks.

## MVP User Roles
- Organization Admin
- Program Director
- Coach
- Assistant Coach
- Parent/Guardian
- Athlete

## MVP Modules
1. People & Relationships
2. Teams & Seasons
3. Notes
4. Events
5. Attendance
6. Tasks
7. Audit Log

## Explicitly Not MVP
- Payments
- Advanced analytics
- AI recommendations
- Inventory
- Health/medical records
- Public team websites
