# Arc 23B — Journal Workflow Validation Checklist

## Journal Workflow

- [ ] Create journal draft
- [ ] Edit journal draft
- [ ] Save draft
- [ ] Finalize/submit journal
- [ ] Archive journal

## Visibility and Authorization

- [ ] Verify author can view own journal
- [ ] Verify authorized staff/admin access
- [ ] Verify coach access is scoped correctly
- [ ] Verify guardian access follows documented policy
- [ ] Verify unrelated guardian cannot access journal
- [ ] Verify unrelated users cannot access journal content

## Feed / Activity Safety

- [ ] Verify journal body does not appear in broad feed/activity
- [ ] Verify activity uses safe labels only (`Journal draft created`, `Journal submitted`, `Journal archived`)
- [ ] Verify no journal body text appears in activity metadata payloads

## UX and Responsiveness

- [ ] Verify mobile journal form is usable
- [ ] Verify status badge states (Draft / Submitted / Archived)
- [ ] Verify clear empty/error/loading states in journals list/detail views

## Deferred Scope Reminder

Not part of Arc 23B:
- Prompt library / prompt assignment
- Habits
- Recurring check-ins
- Journal version history
- Consent workflows
- AI recommendations / sentiment analysis
- External notifications
- Offline journaling
- Rich media journals
