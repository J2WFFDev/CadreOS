# Future Roadmap Placeholder: Mobile App

## Status
Roadmap item only. Not committed for current implementation.

## Goal
Define future CadreOS mobile app direction after mobile web workflows and policy controls are validated.

## Planned Capability Areas

| Area | Future Outcome |
|---|---|
| Operator execution | Fast field workflows for GearOps actions (checkout/check-in/returns) |
| Role-guided access | Role-scoped screens for Equipment Manager, Event Operator, and supporting roles |
| Device integration | Camera/scanner-assisted item lookup and transaction initiation |
| Exception handling | Guided handling for eligibility, approval, and custody conflicts |

## Relationship to Modules
- GearOps is the first mobile-app candidate due to high field-operation intensity.
- CoachOps, FieldOps, and ResourceOps adoption depends on GearOps pilot outcomes.

## Assumptions
- Mobile app design follows proven mobile web workflow patterns.
- Audit integrity and policy gates remain equivalent to desktop/web behavior.

## Open Questions
- Native app, hybrid app, or phased packaging strategy?
- Which role experiences must be in scope for first pilot release?

## Roadmap Dependencies
- Requires mobile web workflow stabilization.
- Requires offline capture and sync policy definition.
- Requires validated GearOps workflow and test scenario baseline.
