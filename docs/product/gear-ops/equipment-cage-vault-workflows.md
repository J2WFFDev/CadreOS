# GearOps Equipment Cage / Vault Workflow Guide

Use this guide for cage/vault operators handling staging, issuing, return intake, and recovery.

## When to Use This

Use this for pre-event staging, daily issue/return windows, and post-event reconciliation.

## Core Workflow

## 1) Stage Gear

- Open event gear plan or item list.
- Move selected items into staging flow.
- Confirm staging location and item list.

## 2) Issue Gear

- Use scan-first checkout for rapid issue.
- Confirm recipient (person/team/event transport) and expected return.
- Verify no existing blocking custody.

## 3) Receive Gear Back

- Process return/check-in against active checkout record.
- Capture condition on return.
- Add return notes if anything is missing/damaged.

## 4) Recover to Storage

- Complete event recovery action to return item to cage/vault location.
- Apply condition and maintenance flags during recovery.
- Update final storage location when needed.

## 5) Verify Returns and Exceptions

Use:
- **GearOps → Reports** exception panels
- **Event Gear → Missing / unreturned view**

Focus on:
- overdue/unreturned custody
- missing requirement fulfillment
- returned-but-not-recovered items

## 6) Handle Damaged or Out-of-Service Gear

- set maintenance path through maintenance log
- keep out-of-service items from redeployment
- route to maintenance workflow before next issue

## 7) Consumable Adjustments at Cage

For consumables:
- record received/used/adjusted transactions
- monitor low-stock thresholds
- escalate replenishment before event day

## 8) Location and Custody Views

- use **Locations** to verify where items should be
- use item detail history for movement and custody chain
- use reports for cross-location discrepancies

## End-of-Day Close Checklist

- all returns processed
- unreturned list reviewed
- recovery completed for returned event gear
- damage/maintenance entries logged
- low consumable alerts reviewed
