# GearOps Reporting and Dashboard Guide

Use this guide for operators, admins, and program managers monitoring gear operations.

## Where to View Reporting

- **GearOps** overview page: quick metrics, exceptions, and pending action summary.
- **GearOps → Reports**: detailed filters, rollups, exceptions, and drill-downs.

## Dashboard Summary Areas

- readiness summary
- custody summary
- location summary
- maintenance summary
- event requirement and recovery summary
- consumable trend summary
- operational exception lists

## Common Exception Types

- out of service
- overdue/unreturned custody
- maintenance needed
- low consumable
- event gear gap
- event gear unreturned

## Filter and Drill-Down Workflow

1. apply filters (category, location, event, lifecycle, owner, assignee, readiness)
2. identify highest-severity exceptions
3. drill into item or event page
4. resolve issue in operational workflow
5. refresh report view to verify closure

## Power User Audit Patterns

Use reports + item/event history to audit:
- custody chain over time
- readiness/maintenance transitions
- event deployment/recovery completion
- recurring low-stock risk in consumables

## Cross-Module Review

When available, use linked people/team/event context on item and event workflows to confirm who had custody and in what operational context.
